# _Uniform_  
: CPU상의 애플리케이션에서 GPU상의 셰이더로 데이터를 전달하는 또 다른 방법 
  1) 전역적
     유니폼 변수는 셰이더 프로그램 객체마다 고유, 셰이더 프로그램의 어느 단계에서든 모든 셰이더에 접근 가능
  2) 유니폼 값을 무엇으로 설정하든 유니폼이 재설정되거나 업데이트될 때까지 그 값을 유지

<br>  

```cpp
#version 330 core
out vec4 FragColor;

uniform vec4 OurColor; //유니폼 키워드와 함께 셰이더에 추가 
void main()
{
FragColor = OurColor;
}
```
->프래그먼트 쉐이더에서 uniform vec4 OurColor를 선언하고 프래그먼트의 출력색상을 이 uniform값으로 설정함. 
uniform은 **_전역변수_** 이므로 원하는 셰이더 단계 어디에서나 접근 가능하기에 버텍스 셰이더를 다시 거칠 필요 X  
<br>  
💡보통 정점별 색상은 버텍스 셰이더->보간->프래그먼트 셰이더로 전달하지만, 유니폼은 그냥 프래그먼트 셰이더에서 직접 접근 가능하다!
